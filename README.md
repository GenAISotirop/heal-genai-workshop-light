# 📚 Από το Prompt στη Δήλωση

> **Εργαστήριο εισαγωγής στην υπεύθυνη χρήση εργαλείων GenAI στην ακαδημαϊκή έρευνα**
> Light Edition · 3 ώρες · single session

[🌐 Δες το live site →](https://USERNAME.github.io/heal-genai-workshop-light/) *(αντικατάστησε USERNAME)*

---

## 📖 Τι είναι

Τρίωρο workshop που μαθαίνει μεταπτυχιακούς φοιτητές πώς να χρησιμοποιούν εργαλεία Τεχνητής Νοημοσύνης (Claude, Consensus) στην ακαδημαϊκή τους εργασία **με τρόπο υπεύθυνο και διαφανή**, σύμφωνα με τις κατευθυντήριες του Συνδέσμου Ελληνικών Ακαδημαϊκών Βιβλιοθηκών (**HEAL-Link / ΣΕΑΒ**).

### Σε ποιους απευθύνεται
- 🎓 Μεταπτυχιακούς φοιτητές πρώτου έτους
- 📚 Διδάσκοντες σε προγράμματα κοινωνικών/εκπαιδευτικών επιστημών
- 🔬 Ερευνητές που θέλουν να ενταχθούν στην ευρύτερη ακαδημαϊκή συναίνεση

### Σε ποιους δεν απευθύνεται
- ❌ Όσους ψάχνουν για "πώς να ξεγελάσω τα AI detection tools"
- ❌ Όσους θέλουν να αντικαταστήσουν τη συγγραφική τους εργασία με ΤΝ

---

## 🎯 Τι θα μάθεις σε 3 ώρες

| Ενότητα | Διάρκεια | Παραδοτέο |
|---|---|---|
| 1. Ηθική + HEAL-Link + Σενάρια | 35' | Υπογεγραμμένο AI Usage Agreement |
| 2. Prompt Engineering | 45' | 5 δοκιμασμένα prompts |
| 3. Research Mini-Tour | 60' | Hands-on practice σε 4 εργαλεία |
| 4. Documentation + Δήλωση | 20' | Draft HEAL-Link Statement |
| 5. AI Detection + Q&A | 5' | — |

---

## 🛠 Εργαλεία που θα δεις

- **[Claude](https://claude.ai)** — Large Language Model για prompting
- **[Consensus](https://consensus.app)** — Peer-reviewed paper search
- **[Rayyan](https://rayyan.ai)** — Συστηματικό screening χωρίς ΤΝ
- **DOI Verification** — Επαλήθευση ακαδημαϊκών αναφορών
